# Knowledge Base — Starter Docs

This folder holds the curated condition docs that SymptomScout retrieves over.

**Framing:** SymptomScout helps **anyone** prepare for a doctor's visit. The knowledge base targets conditions that are **frequently dismissed, misattributed, or diagnosed late — across all patients**, not any one group. Some conditions skew toward a particular sex (and the docs state that accurately where it's clinically true), but the product is universal: it improves the information a person brings to a visit, for everyone.

**Status:** 4 starter docs included as placeholders so the scaffold runs end-to-end. **JP to expand and clinically review before the workshop.** Target: 10–20 conditions across the commonly-dismissed / late-diagnosed space.

## Doc format

Each file: one condition, one page. Sections:

1. **Typical presentation** — what symptoms cluster
2. **Often-missed signs** — what gets dismissed or misattributed
3. **Tests to ask for** — specific labs / imaging / referrals
4. **Questions to bring to the doctor** — empowerment language
5. **Sources** — real URLs, organizations (Mayo, NIH, NORD, NHS, specialty societies)
